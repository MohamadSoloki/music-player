# موزیک پلیر من (برنامهٔ ویندوز) (با تشکر از ALEX عزیز بابت اینکه کل کار کلاد رو انجام داد)

زبان رابط برنامه انگلیسی است (نام آهنگ‌ها و خواننده‌ها همچنان به فارسی درست نمایش داده می‌شوند).

برنامه با Tauri ساخته شده و فایل نصب (`.exe`) را GitHub برای تو می‌سازد. لازم نیست چیزی روی کامپیوترت نصب کنی.

## راه‌اندازی (یک بار)

1. در github.com حساب رایگان بساز.
2. یک مخزن (Repository) جدید بساز. نام: `music-player`. نوع آن را **Public** بگذار.
   دلیل: برنامه برای دیدن آپدیت از اینترنت و بدون ورود به حساب به فایل‌های نسخه دسترسی دارد. در مخزن خصوصی این کار نمی‌شود.
   کلید امضا در مخزن نیست و داخل Secrets است، پس عمومی بودن کد خطری برای آپدیت‌ها ندارد.
3. محتوای همین پوشه (نه خود پوشه) را در مخزن آپلود کن: **Add file ← Upload files** و همهٔ فایل‌ها و پوشه‌ها را بکش و رها کن. پوشهٔ `.github` هم باید باشد. بعد **Commit changes**.
4. کلید امضا را ثبت کن: **Settings ← Secrets and variables ← Actions ← New repository secret**
   - Name: `TAURI_SIGNING_PRIVATE_KEY`
   - Secret: کل محتوای فایل `musicplayer.key` که جدا فرستاده شده
5. اولین نسخه: تب **Actions ← Release ← Run workflow**، در خانهٔ نسخه بنویس `0.1.0` و اجرا کن. حدود ۱۰ تا ۲۰ دقیقه طول می‌کشد.
6. وقتی تمام شد، در صفحهٔ **Releases** فایل `MusicPlayer_0.1.0_x64-setup.exe` را دانلود و نصب کن.

## آپدیت دادن

1. فایل جدید `src/index.html` را در مخزن جایگزین کن (باز کردن فایل ← آیکون مداد، یا Upload files).
2. دوباره **Actions ← Release ← Run workflow** و شمارهٔ بزرگ‌تر بنویس (مثلاً `0.1.1`).
3. برنامهٔ نصب‌شده هنگام باز شدن (و هر ۶ ساعت) نسخهٔ جدید را چک می‌کند. بنر «New version … is ready» می‌آید؛ با زدن **Update** خودش دانلود، نصب و دوباره باز می‌شود. پایین سمت چپ برنامه هم دکمهٔ «Check for updates» هست.

## نکته‌های مهم

- فایل `musicplayer.key` را جای امن نگه‌دار (مثلاً یک نسخهٔ پشتیبان). اگر گم شود، آپدیت‌های خودکار کار نمی‌کنند و باید دوباره دستی نصب کنی. آن را هرگز در مخزن آپلود نکن.
- شمارهٔ نسخه هر بار باید بزرگ‌تر از قبلی باشد، وگرنه برنامه آپدیت نمی‌بیند.
- آهنگ‌ها و پلی‌لیست‌ها با آپدیت پاک نمی‌شوند.
- نصب بدون دسترسی ادمین انجام می‌شود. ویندوز ممکن است بار اول هشدار «ناشناس» (SmartScreen) بدهد، چون برنامه گواهی تجاری ندارد: **More info ← Run anyway**.

## پوشهٔ آهنگ‌ها

- آهنگ‌ها داخل پوشهٔ برنامه ذخیره می‌شوند: `C:\Users\نام-تو\AppData\Roaming\com.disrespect.musicplayer\Music`
  دکمهٔ **Open folder** بالای لیست، همین پوشه را در Explorer باز می‌کند.
- هر آهنگی که با دکمهٔ «Add songs» یا کشیدن و رها کردن اضافه کنی، به این پوشه کپی می‌شود.
- آهنگ تکراری (فایلی که محتوایش دقیقاً با یکی از آهنگ‌های کتابخانه یکی باشد، حتی با نام دیگر) با دکمهٔ «Add songs» یا کشیدن و رها کردن اضافه نمی‌شود، به پوشه کپی نمی‌شود و پیام «Duplicate song» می‌بینی.
- آهنگی را که خودت دستی در این پوشه (یا زیرپوشه‌هایش) بریزی، با زدن **Refresh folder** به برنامه اضافه می‌شود. هنگام باز شدن برنامه هم خودکار چک می‌شود.
- اگر فایلی را از پوشه پاک کنی، با رفرش از کتابخانه و پلی‌لیست‌ها هم حذف می‌شود.
- حذف آهنگ از داخل برنامه، فایل را به سطل بازیافت ویندوز می‌برد و از آنجا می‌توانی برش گردانی. برنامه فقط فایل‌های داخل پوشهٔ آهنگ‌ها را به سطل می‌فرستد.
- نام، خواننده، آلبوم و عکسی که ویرایش می‌کنی به‌صورت پیش‌فرض داخل خود برنامه نگه داشته می‌شود. اگر فایل را در پوشه تغییر نام بدهی، برنامه آن را آهنگ جدید می‌بیند.

## یک پنجره در هر لحظه

برنامه فقط یک نمونه (instance) دارد. اگر دوباره روی آیکون برنامه بزنی، پنجرهٔ باز قبلی (حتی اگر کوچک شده باشد) بالا می‌آید و پنجرهٔ جدیدی باز نمی‌شود. نسخهٔ dev شناسهٔ جدا دارد، پس می‌تواند همزمان با برنامهٔ نصب‌شده باز باشد.

## ظاهر و رنگ‌ها (Appearance)

پایین منوی کناری، **Appearance**: چند تم آماده و انتخاب رنگ اصلی (دکمه‌ها)، پس‌زمینه، پنل‌ها، متن و دکمهٔ پخش. تغییرات همان لحظه دیده و ذخیره می‌شوند.

## پشتیبان‌گیری

- برنامه خودکار نام، خواننده، آلبوم، عکس، پلی‌لیست‌ها (با ترتیبشان)، علاقه‌مندی‌ها، تعداد پخش و تنظیمات (رنگ‌ها، سرعت و پیچ، اکولایزر) را در پوشهٔ `data` کنار پوشهٔ آهنگ‌ها ذخیره می‌کند: `C:\Users\نام-تو\AppData\Roaming\com.disrespect.musicplayer\data\library.json`
- اگر داده‌های داخلی برنامه پاک شود، با باز شدن برنامه همین اطلاعات خودکار برمی‌گردند. یک نسخهٔ قبلی هم با نام `library.prev.json` نگه داشته می‌شود.
- در منوی کناری، **Backup** می‌توانی همین حالا ذخیره کنی، از پشتیبان بازیابی کنی یا پوشه را باز کنی.
- آهنگ‌ها در پشتیبان با مسیر فایلشان شناخته می‌شوند. پس فایل‌ها را داخل پوشهٔ آهنگ‌ها با همان نام نگه دار.

## امکانات پخش

- **ادامهٔ پخش:** برنامه بعد از بستن، آخرین آهنگ و جای آن را یادش می‌ماند و بدون پخش خودکار آماده می‌گذارد.
- **صف پخش:** با منوی ⋮ (یا کلیک راست) روی هر آهنگ، «Play next» یا «Add to queue» را بزن. دکمهٔ صف کنار نوار پخش، صف را نشان می‌دهد و می‌توانی ترتیبش را عوض کنی.
- **پلی‌لیست:** آهنگ‌ها را با کشیدن و رها کردن جابه‌جا کن (در جستجو غیرفعال است).
- **اکولایزر:** پنج باند و چند حالت آماده. وقتی همهٔ باندها صفر باشند، هیچ پردازشی انجام نمی‌شود.
- **تایمر خواب:** ۱۵ تا ۹۰ دقیقه یا پایان آهنگ فعلی. صدا در ۲۰ ثانیهٔ آخر آرام کم می‌شود.
- **Favorites و Recently played:** با قلب کنار آهنگ. تعداد پخش هم ذخیره می‌شود و می‌توانی بر اساس «Most played» مرتب کنی.

## نوشتن مشخصات روی فایل MP3 (اختیاری)

در پنجرهٔ ویرایش آهنگ‌های MP3 گزینهٔ «Also write changes into the MP3 file itself» هست. اگر روشنش کنی، نام، خواننده، آلبوم و عکس داخل خود فایل هم نوشته می‌شود و در گوشی و برنامه‌های دیگر دیده می‌شود.

- بخش صوتی فایل بایت‌به‌بایت همان می‌ماند و فریم‌های دیگر تگ (مثل ژانر و توضیحات) حفظ می‌شوند.
- نتیجه اول در یک فایل موقت نوشته و بررسی می‌شود. فقط اگر درست بود جای فایل اصلی می‌نشیند؛ در غیر این صورت فایل اصلی دست‌نخورده می‌ماند.
- فایل‌هایی با تگ ID3v2.2 یا ساختار غیرمعمول تغییر داده نمی‌شوند. نام و عکس در این حالت فقط داخل برنامه ذخیره می‌شود.

## مصرف کم رم و پردازنده

- لیست آهنگ‌ها مجازی است و فقط ردیف‌های دیده‌شده ساخته می‌شوند؛ کتابخانهٔ بزرگ هم سبک می‌ماند.
- عکس‌ها فقط وقتی دیده می‌شوند بارگذاری می‌شوند و تعدادشان در رم محدود است.
- موتور پردازش صدا فقط وقتی ساخته می‌شود که پیچ یا اکولایزر را تغییر داده باشی. بخش‌های خاموش از مسیر صدا کنار گذاشته می‌شوند و وقتی پخش نیست، موتور صدا می‌خوابد.

## اجرای محلی برای توسعه (بدون ریلیز)

برای دیدن تغییرات همان لحظه، لازم نیست ریلیز بسازی. یک بار این‌ها را روی ویندوز نصب کن: Node.js (نسخهٔ LTS)، Rust از rustup.rs و «Microsoft C++ Build Tools» (گزینهٔ Desktop development with C++). WebView2 روی ویندوز ۱۰ و ۱۱ از قبل هست.

```
git clone https://github.com/MohamadSoloki/music-player.git
cd music-player
npm install
npm run dev
```

- بار اول کامپایل Rust چند دقیقه طول می‌کشد. بعد از آن اجرا سریع است.
- با تغییر دادن `src/index.html` و ذخیره کردنش، پنجرهٔ برنامه خودکار دوباره بارگذاری می‌شود. اگر نشد، داخل پنجره `Ctrl+R` بزن. با تغییر فایل‌های Rust (داخل `src-tauri`) برنامه خودش دوباره ساخته و اجرا می‌شود.
- نسخهٔ dev با شناسهٔ جدا (`com.disrespect.musicplayer.dev`) اجرا می‌شود، پس پوشهٔ آهنگ‌ها و داده‌هایش جدا از برنامهٔ نصب‌شده است: `C:\Users\نام-تو\AppData\Roaming\com.disrespect.musicplayer.dev\Music`. آهنگ‌های آزمایشی را همان‌جا بریز.
- در نسخهٔ dev بررسی آپدیت کار نمی‌کند. این طبیعی است و جلوی نصب اشتباهی روی برنامهٔ اصلی را می‌گیرد.
- برای ابزار توسعه (Inspect و Console) در پنجرهٔ برنامه کلیک راست کن و Inspect را بزن، یا `F12`.
- ریلیز فقط وقتی لازم است که بخواهی نسخه برای نصب و آپدیت خودکار منتشر شود.
